# File and Folder Management System

A Python-based command-line application for managing files and folders using Python's built-in file handling and filesystem modules.

## Features


- Create folders
- List files and folders recursively using `rglob()`
- Rename folders
- Delete folders
- Create and write to files
- Read file contents
- Rename files
- Append data to files
- Overwrite file contents
- Delete files

## Technologies Used

- Python
- pathlib
- shutil
- os

## Concepts Covered

- File Handling
- Folder Management
- `Path` and `pathlib`
- Recursive File Searching with `rglob()`
- File and Folder CRUD Operations
- Exception Handling
